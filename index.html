🔌 Plug & Play Custom Event Creation

The kernel architecture allows registering any festive event (🪔 Diwali, 🎄 Christmas, 🎆 New Year) in 3 simple steps: 

import { registerEvent, start } from '@event-overlay/core';

// 1. Define custom EventModule
export const DiwaliEvent = {
    id: 'diwali',
    name: 'Diwali Celebration',
    init(ctx, width, height, options) { /* Setup diyas, sparklers, lanterns */ },
    update(time, delta, width, height) { /* Physics update loop */ },
    draw(ctx, width, height, time) { /* Render on high-DPI canvas */ },
    destroy() { /* Cleanup resources */ }
};

// 2. Register module
registerEvent(DiwaliEvent);

// 3. Start anywhere
start('diwali');
